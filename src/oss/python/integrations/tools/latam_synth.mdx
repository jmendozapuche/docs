This guide provides a quick overview for getting started with the LatAm Synth [tool](/oss/langchain/tools). LatAm Synth generates synthetic financial users, savings goals, and transactions for Latin American fintech testing, AI agent evaluation, machine-learning experiments, demos, and data pipelines without using personally identifiable information.
